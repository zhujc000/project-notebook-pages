PERSONAL PROJECT NOTEBOOK

项目有来由，进展有记录。

项目手记是一款个人使用的项目管理工具，用来记录项目背景、阶段进度、问题和评审结论。

Google 授权配置中的名称为“项目管理chatgpt”。本页介绍同一应用的功能与数据使用方式。

记录与整理

  • 保存项目背景、目标、原始笔记、最新进度与待解决问题。
  • 跟踪 IPD 阶段、评审节点和评审结论。
  • 通过网页或已连接的 ChatGPT 应用整理更新项目记录。
  • 按需导出项目数据，或连接自己的 Google Drive 保存备份。

可选的 Google Drive 备份

你主动连接并启用备份后，应用在数据变更时尝试更新同一个压缩 JSON 备份文件，也支持手动同步。备份用于保存项目记录；授权失效或网络异常时，需要重新连接或重试。

应用仅申请 drive.file 文件权限，备份功能只处理自身创建的备份文件，不扫描你的整个云端硬盘。

访问应用

打开项目手记（需要获准的 ChatGPT 账号登录）。此公开说明站不展示项目记录，也不提供备份下载。

使用前可阅读隐私政策和服务条款。

联系与支持

GitHub 支持反馈（请勿提交项目内容、授权令牌或密钥）
