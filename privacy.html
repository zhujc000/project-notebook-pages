隐私政策

适用于项目手记（Google 授权名称：项目管理chatgpt） · 更新于 2026-10-24

1. 数据与用途

应用保存你主动录入的项目背景、进度、问题、笔记、IPD 节点、评审和操作记录，用于项目管理与导出。应用使用登录身份区分数据所属用户。

连接 Google Drive 后，应用保存实现备份所需的 OAuth 授权信息、备份文件标识及同步状态。Google 登录与授权在 Google 页面完成，应用不收集 Google 账号密码。

2. Google Drive 权限与处理方式

备份功能申请 https://www.googleapis.com/auth/drive.file 权限。该权限允许处理应用创建或由用户向应用开放的文件。本应用当前仅用它创建、读取验证和更新自己的项目备份文件，不列举或读取云端硬盘内的其他无关文件。

启用后，项目导出数据会发送到你授权的 Google Drive，写入“项目手记-自动备份.json.gz”。应用尽量更新同一个文件；Google Drive 可能保留历史版本。备份是压缩文件，应用未对备份文件内容另行加密。

3. 存储与服务提供方

项目记录和备份配置保存在应用托管环境中。Google 刷新令牌与客户端密钥以加密形式存储。应用通过 HTTPS 与 Google 通信。备份内容保存在你授权的 Google Drive，适用 Google 的存储与账号政策。

应用依赖 ChatGPT Sites 的身份和托管服务以及其基础设施。你在 ChatGPT 中主动提交或请求整理的内容，会由 ChatGPT 按你的设置和 OpenAI 适用政策处理。备份模块不会将从 Google Drive 读取的备份内容发送给 AI 模型。

4. Google 用户数据的使用限制

通过 Google API 获取的数据仅用于提供和维护用户请求的备份功能。应用不将这些数据出售、用于广告、信用评估或训练通用 AI 模型；仅在实现上述功能所需的服务处理、获得用户同意或法律要求的情况下传输。

项目手记对从 Google API 接收的信息的使用及向其他应用的转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

5. 保留、断开与删除

项目记录保留至你删除相应数据或要求维护者删除。备份连接信息在功能使用期间保留。断开 Google Drive 会停止后续同步并清除应用保存的授权令牌；客户端配置及备份文件标识可能继续保留以支持重新配置。

断开不会删除 Google Drive 中已有的备份文件。你可以在云端硬盘中自行删除备份并清空垃圾箱；需要彻底撤销授权时，可到 Google 账号的第三方连接页面移除本应用的访问权限。

需要删除全部应用数据或残留配置时，请通过下方渠道联系维护者。删除应用数据不会自动删除你自行导出的文件或云端硬盘的历史副本。

6. 本公开说明网站

此站点仅提供静态介绍与政策页面，不包含项目数据库、Google 密钥或备份文件，不主动设置分析追踪脚本。GitHub Pages 托管服务可能按 GitHub 隐私声明处理访问日志等技术信息。
